# 🎡 観覧車 v7 — 自動回転・安全版（9/23 生成AIなんでも展示会）

7/24 AI Dev Day で展示した手回し観覧車（v6）を、<b>モーター＋ウォームギアで回転を完全に固定した自動回転システム</b>に再構築します。既存の印刷パーツ（リム8・ハブ2・支柱・ゴンドラ4・Φ8鋼シャフト・LED一式）はそのまま流用し、<b>追加するのは「支柱上部1個・モーターブラケット・制御基板＋筐体」だけ</b>です。

::: danger 7/24 に起きたこと（再設計の理由）
- 実機スタックチャン（K151・約190g）を乗せると <b>ゴンドラが重く、来場者がクランクを速く回すと振り子が振れ切ってスタックチャンが飛び出す</b>ことがあった。
- クランク直結（減速なし）なので、<b>子どもが触れば何回転でも回せてしまう</b>。回転速度を機構で制限できないのが根本原因。
:::

::: tip v7 の結論
1. <b>駆動</b>: JGY-370 12V <b>ウォームギアモーター（3rpm）</b> をΦ8シャフトに直結。ウォームは<b>逆駆動不能（セルフロック）</b>＝外からリムを押しても回らない。回転速度は 3rpm 固定（1周20秒・リム周速 47mm/s）なので振り子は振れない。
2. <b>安全</b>: 非常停止（12V物理遮断）＋モータードライバの電流制限（1.25A）＋ホールセンサによるストール検知＋モーター/カップリングは箱型ブラケットで覆う。
3. <b>制御</b>: EasyEDA で <b>AtomS3R キャリア基板</b>（電源・DRV8871・コネクタ）を作り JLCPCB へ発注。MCU は手持ちの AtomS3R を挿すだけ。LED ファームはそのまま統合。
4. <b>印刷は先行</b>: 新規パーツ 5 種（合計約 5 時間）を今週中に印刷する。基板が届く前に機構は組めるようにする。
:::

> `cad/ferris/assembly.scad PART="all-v7"` のレンダリング。<a href="/viewer/" target="_blank">3D組立シミュレーター</a>にも「駆動」「制御」グループとして反映済み（モーターブラケット・カップリング・モーター・制御ボックス・基板・操作パネル・配線）。

### 制御の構成（PCB は「土台」・頭脳は AtomS3R）

- <b>AtomS3R を基板のソケットに挿す</b>。モーター PWM・ポット・ホール・ボタン・非常停止検知は Atom の底面 6 GPIO、LED は従来通り Grove から出す。
- <b>基板に載るのは接続部分だけ</b>: 12V 入力（ジャック・ヒューズ・逆接保護）→ モータードライバ DRV8871 → モーター用コネクタ、12V→5V 降圧（LED・Atom 給電）、LED データのレベルシフタ、各パネル部品用の XH コネクタ。マイコン・無線・書込み回路は基板に無い。
- 非常停止・速度ツマミ・RUN/STOP ボタンは<b>筐体の蓋の操作部ベイ</b>（基板の隣）に付け、基板へは XH ケーブルで接続。基板の上には何も垂れないので部品高さの制約なし。

## 「ギアで固定」の解釈と方式選定

| 方式 | 回転の固定 | 実装量 | 判定 |
|---|---|---|---|
| <b>ウォームギアモーター直結</b>（採用） | モーター停止中もリムは動かない（セルフロック）。速度はモーターで固定 | 支柱1・ブラケット1・基板 | ✅ 最小変更で要件を満たす |
| 印刷平歯車＋DCモーター | 逆駆動できてしまう（減速比を上げれば重いが固定ではない） | 大歯車＋ピニオン＋軸受 | ✖ 固定にならない |
| ステッピングモーター（28BYJ-48 等） | 通電中は保持。トルク 0.03N·m で不足（必要 0.52N·m） | 追加減速機構が必要 | ✖ トルク不足 |
| ゴンドラ水平保持ギア（太陽歯車＋アイドラ） | ゴンドラの振れを機構で禁止 | 歯車 12 枚＋固定歯車支持 | ⏸ 低速回転なら不要。9/23 後の拡張候補（[付録](#付録-ゴンドラ水平保持ギアオプション)） |

<b>必要トルクの見積り</b>: 最悪ケース＝片側 2 台・反対側 0 台 → `2 × 0.19kg × 9.81 × 0.14m = 0.52 N·m（5.3 kgf·cm）`。JGY-370 12V 3rpm の定格トルクは約 10 kgf·cm（[RobotShop 仕様](https://www.robotshop.com/products/aslong-motor-jgy370-12v-6rpm-high-torque-worm-gear-motor)・Amazon 掲載値は 25 kgf·cm）→ <b>余裕 1.9〜4.7 倍</b>。4 台満載の通常運用では不均衡はほぼゼロ。

<b>挟まれリスク</b>: 定格 10 kgf·cm がリム外周 r=150 に出す力は `0.98 N·m / 0.15 m ≈ 6.5 N（0.67 kgf）`。さらに DRV8871 の電流制限で実トルクはこれ以下。指を挟んでも怪我にならない領域で、かつ 47mm/s の低速。

## 電装設計（制御基板 = AtomS3R キャリア）

MCU を新規に基板へ載せず、<b>手持ちの AtomS3R をソケットに挿す</b>構成にします。理由: (1) 既存 LED ファームと書込み環境をそのまま使える、(2) 画面とボタンが付いてくる（状態表示・現場操作）、(3) JLC 組立部品が電源とドライバだけになり、基板の失敗リスクが最小。

詳細（ネットリスト・BOM・発注手順・プラン B）は [`hardware/ferris-ctrl-pcb/README.md`](https://github.com/aieo-product/stackchanEventBooth/blob/main/hardware/ferris-ctrl-pcb/README.md) と [`bom-jlcpcb.csv`](https://github.com/aieo-product/stackchanEventBooth/blob/main/hardware/ferris-ctrl-pcb/bom-jlcpcb.csv)。

```
12V 2A ACアダプタ ─ 2Aポリスイッチ ─ 逆接保護 ─┬─ [非常停止 常閉] ─ DRV8871 (ILIM 1.25A) ─ JGY-370
                                             └─ LM2596S-5.0 (3A) ─┬─ AtomS3R 5V
                                                                  └─ SK6812 60LED ×2（既存）
AtomS3R: G5/G6=PWM → DRV8871、G7=速度ポテンショ、G8=ホールセンサ、G38=RUN/STOPボタン、G39=非常停止検知
         Grove G1/G2 → 74AHCT1G125 → LED Din（既存配線・JST SM ピグテールをそのまま接続）
```

| 項目 | 仕様 |
|---|---|
| 基板 | 80×60mm・2層・M3×4（角から4mm）・Atom 中心 (20,30)・コネクタは +Y 辺 ← <b>`cad/params.scad` の `pcb_*` と同期</b> |

| 電源 | 12V 2A（モーター定格 0.2A・LED 上限 0.9A・Atom 0.3A → 余裕大） |
| 非常停止 | 22mm キノコ型（1NC+1NO）。NC でモーター 12V を<b>物理遮断</b>、NO で Atom に検知 |
| 速度 | 10kΩ ポテンショ → 30〜100% デューティ（ウォームは低デューティで止まるため下限あり） |

### ファームウェア `firmware/ferris_ctrl/ferris_ctrl.ino`（コンパイル済み・AtomS3R）

- 起動＝STOP。外部ボタン短押し／画面ボタン長押しで RUN⇄STOP。RUN は 2 秒ソフトスタート。
- 画面: 状態（STOP/RUN/STALL/E-STOP）・速度%・LED 輝度・周回数。画面ボタン短押しで LED 輝度 50/25/100/OFF（従来と同じ）。
- LED レインボーは `led_rainbow.ino` と同一（電流上限 900mA）。
- 非常停止中は PWM=0 かつ 12V も遮断。復帰は非常停止解除→ボタン。

## 安全設計まとめ（子ども対応）

| リスク | 対策 |
|---|---|
| 手でリムを回される | ウォームのセルフロック＝回らない（無理に回すとモーターの歯を痛めるので、リム外周に「さわらないでね」表示＋スタッフ声かけ） |
| ゴンドラを押す・引く | 3rpm で振り子は自然に静止。ゴンドラは従来通り自由振子（ロックすると逆さになる）。搭乗機はゲルテープ＋2段ポケット＋ラップバー |
| 指を挟む | トルク上限（電流制限）・周速 47mm/s・カップリング/モーター軸はブラケットで密閉 |
| 暴走・故障 | 非常停止（物理遮断）・ストール検知・ポリスイッチ・逆接保護 |
| 発熱 | JGY-370 定格 0.2A・連続運転 4h 想定でも問題なし。筐体に通気スリット |

## 付録: ゴンドラ水平保持ギア（オプション・9/23 後）

固定太陽歯車（支柱に固定・シャフトと非結合）＋各ゴンドラ軸の同歯数歯車を<b>アイドラ 1 枚</b>で結ぶと、リムが回ってもゴンドラ歯車は世界座標で回転せず、ゴンドラが常に水平に<b>機構固定</b>されます（`ω_gondola = ω_rim × (1 − N_sun/N_gondola) = 0`）。m1.5 で 太陽 40T（r30）・ゴンドラ 40T（r30）・アイドラ pitch Ø80 の 3 段が半径 140 に収まります。歯車 12 枚（約 6h 印刷）とリム片側の再設計が必要なため、v7 では採用せず低速回転で代替します。
